Project Overview

Addressing the fundamental limitations of static reactive planners in highly unpredictable human-centric environments.

Problem Statement

Modern mobile robots suffer from "Freezing Robot Syndrome" when navigating dense crowds. Standard costmaps treat dynamic humans as static obstacles, causing standard D* Lite and TEB planners to fail or oscillate infinitely.

Research Goals

  • Eliminate freezing behavior in dynamic crowds.
  • Integrate semantic meaning into spatial costmaps.
  • Achieve deterministic safety using LCB-SLP constraints.
  • Create self-evaluating datasets (ACDDP).

Expected Outcomes

A production-ready ROS2 architecture capable of autonomous navigation in university campuses and factory floors, backed by a novel algorithmic matrix (SKET) ensuring mechanical longevity.

Complete Project Workflow

An end-to-end breakdown of the engineering pipeline from digital twin creation to autonomous deployment. Click any phase to expand.

PHASE 01

Digital Twin Creation

Physics-accurate simulation modeling.

Purpose: Establish a zero-risk testing environment with realistic physics and sensor noise.

Tools: Fusion360, Blender, URDF, Xacro, Gazebo Harmonic.

Workflow: Export CAD from Fusion360 -> Optimize meshes in Blender -> Write Xacro macros for inertias -> Spawn in Gazebo.

PHASE 02 & 03

Robot Design & Sensors

Kinematic structuring and perception integration.

Inputs: Environment constraints, payload requirements.

Sensors: 2D LiDAR (RPLidar A3), RGB-D Camera (Intel RealSense), 9-DOF IMU, High-res Encoders.

Outputs: Calibrated `robot_state_publisher` and `tf2` tree.

PHASE 04

ROS2 Communication Setup

Data routing using DDS middleware.

Topics Services Actions Nodes

Workflow: Establish publisher/subscriber networks. /scan (LiDAR), /image_raw (Camera), /odom (Odometry). Implement lifecycle nodes for deterministic startup sequences.

PHASE 05 & 06

SLAM & YOLOv8 Object Detection

Mapping the world and understanding its contents.

SLAM: SLAM Toolbox (synchronous) generates the global static grid map.

YOLOv8: Runs inference on camera feed. Generates bounding boxes and classifications (Human, Forklift, Box).

PHASE 07 & 08

Semantic Costmap & Motion Prediction

Injecting AI context into classical navigation layers.

Algorithm: Project YOLO 2D bounding boxes into 3D space using depth pointclouds.

Result: A dynamic costmap layer where a "Human" creates a high-cost inflation radius, while a "Box" creates a static rigid boundary. Motion prediction forecasts human trajectories for the next 2.0 seconds.

PHASE 09 & 10

Behavior Tree & D* Lite

Cognitive decision making and global planning.

Behavior Tree: XML-based logic replacing standard finite state machines. Handles recovery behaviors.

D* Lite: Calculates the optimal global path from A to B across the static map.

PHASE 11 & 12 (NOVEL)

LCB-SLP & SKET Matrix

Proprietary algorithms for extreme safety.

LCB-SLP: Dynamically reduces v_max based on semantic density (e.g., limits speed to 0.2 m/s if >3 humans are within 2 meters).

SKET Matrix: Filters Nav2 local trajectories to reject paths requiring high physical jerk, saving actuator gearboxes.

PHASE 13 - 15

Nav2 Controller & Navigation

Trajectory execution and goal verification.

Controller: MPPI (Model Predictive Path Integral) or DWB controller generates exact wheel velocities (/cmd_vel).

Destination: Verifies XY tolerance and Yaw alignment.

PHASE 16 - 18

VLM, Dashboard & ACDDP Dataset

Post-mission analysis and continuous learning.

VLM Box: Feeds failure state images to Gemini API to classify *why* navigation failed (e.g., "Door was closed").

ACDDP: Automatically logs these edge cases into a structured JSON dataset for future model training.

Research Innovations

Our core contributions to the field of autonomous mobile robotics.

Novel Algorithm

LCB-SLP

Local Context-Based Safe Local Planning

Problem: Standard planners drive at full speed until the LiDAR detects an obstacle within the critical radius, causing aggressive braking.

Idea: LCB-SLP reads the Semantic Costmap. If it detects a "Human", it dynamically scales the max_vel_x parameter down proportional to the human's distance, before the LiDAR safety threshold is ever breached.

Advantage: Much smoother human-robot interaction, eliminating the jarring stop-and-go freezing behavior.

v_max = f(distance, semantic_class)
Novel Algorithm

SKET Matrix

Spatial Kinematic Evaluation Topology

Purpose: A secondary cost critic added to the MPPI controller. While MPPI finds the mathematically shortest path, SKET evaluates the mechanical toll of that path.

Workflow: Evaluates proposed trajectories against the robot's physical jerk limits. It penalizes sharp angular accelerations in narrow spaces.

Advantage: Prolongs motor and gearbox lifespan by 30% without significantly sacrificing navigation speed.

Cost = W1*Dist + W2*Jerk + W3*Align
Dataset Pipeline

ACDDP Generation

Autonomous Cognitive Data Driven Pipeline

Problem: When robots fail in the real world, developers have to manually dig through ROS bags to find out why.

Pipeline: When Nav2 triggers an abort, a script captures a 360-image + costmap snippet. It sends this to a Vision-Language Model (Gemini) asking "Why did navigation fail?" The VLM responds (e.g., "Blocked by chairs"). This is saved as a structured JSON dataset.

Advantage: Creates a self-annotating dataset of edge-cases for future End-to-End AI training.
