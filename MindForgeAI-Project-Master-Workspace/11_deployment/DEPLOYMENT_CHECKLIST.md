# Deployment Checklist

- [ ] Target environment and architecture approved
- [ ] Dependencies pinned and clean build succeeds
- [ ] Configuration externalised; no secrets committed
- [ ] Container / runtime starts from documented commands
- [ ] Data, model and storage paths validated
- [ ] Health check and smoke test pass
- [ ] Logs and error handling verified
- [ ] Access, privacy and security checks completed
- [ ] Performance checked using realistic inputs
- [ ] Monitoring and owner identified
- [ ] Rollback procedure tested
- [ ] Release version, links and evidence recorded
- [ ] User guide and operations runbook complete
